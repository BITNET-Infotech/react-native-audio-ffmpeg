# react-native-audio-ffmpeg

Universal audio processing for React Native — merge, convert, trim, and more. Built as a **New Architecture Turbo Module** with FFmpeg.

## Installation

```bash
npm install @bitnet-infotech/react-native-audio-ffmpeg
# or
yarn add @bitnet-infotech/react-native-audio-ffmpeg
```

**Package:** `@bitnet-infotech/react-native-audio-ffmpeg` (public scoped package on npm).

**Peer dependencies:** React 19+ and React Native 0.85+.

### iOS

```bash
cd ios && pod install && cd ..
```

## Documentation

See [USAGE.md](./USAGE.md) for the full API reference, file paths, permissions, and recipes.

## Example app

The [`example/`](./example/) app demonstrates convert and merge flows. From the repo root:

```bash
yarn bootstrap
yarn --cwd example start
```
